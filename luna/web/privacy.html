Privacy

On your phone

Luna is a fictional AI companion for adults. Messages, summaries, companion settings, avatars and memories are stored in app-private storage. Android backup is disabled. Uninstalling the app removes its data. Chat history, saved memories, cache and model files have separate deletion controls.

Network requests

Model downloads reach GitHub. An optional, user-initiated report sends only a selected category to the project’s Vercel report handler. Never include a private message. The operator reviews categories through runtime logs. GitHub and Vercel may process ordinary network metadata such as IP addresses.

Voice and website settings

Voice input uses Android’s on-device recognizer where available. Read-aloud uses installed offline voices. This website stores preview preferences in browser local storage. Clearing site data removes them.
