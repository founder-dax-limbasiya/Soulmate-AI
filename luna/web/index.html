☾   ANDROID SETUP

Bring Luna to your phone.

Open the Android project

Download the source branch below and extract the ZIP. In Android Studio choose Open, select the luna folder, then allow Gradle to sync. The first build needs internet for Android build tools and the native engine.

Browse Android source ↗
Run on an Android phone

Use a 64-bit ARM phone running Android 9 or later. Enable Developer options and USB debugging, connect the phone, accept its debugging prompt, select it in Android Studio, and press Run.

Install a model and chat offline

Open Settings in Luna. Choose Compact or Balanced, then download the model from GitHub Releases or import its matching official GGUF file. Luna verifies the file before installation. Once installed, turn on airplane mode and send a message.

Privacy, costs and release status

Luna is an artificial companion for adults. Chat and memory live on the phone. Optional reports send only a selected category. Model downloads use data. This is a source build for testing. Device performance and language quality need validation before a public release.
